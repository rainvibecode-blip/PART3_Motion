# 씬 8종: 비트표와 바꿀 곳 (`assets/scenes/`)

각 파일은 HyperFrames 씬 하나다(`<template>` 안에 스타일·마크업·스크립트). 씬 id와 요소 접두어는 두 글자다.

- 예: `dg` 씬의 요소는 모두 `dg-…`.
- 호스트 `id`, 씬 루트의 `data-composition-id`, `__timelines["…"]` 키가 모두 같아야 한다.

| id | 파일 | 길이 | 캔버스 | 핵심 기법 |
| --- | --- | --- | --- | --- |
| `hl` | headlines.html | 4.6초 | 좌 다크 / 우 라이트 | 헤드라인 카드 블러 인 + 키워드 박스 와이프 |
| `tk` | talk.html | 7.5초 | 토킹헤드 | 키네틱 자막, 모프 스티커, CTA, TV 끄기 |
| `ch` | chapter.html | 2.8초 | 챕터 | 1프레임 플래시, 금색 사선, 고정 |
| `dg` | diagram.html | 7.5초 | 라이트 | 숫자 원 → 그룹 → 카드 → 선택 상태, 줌 스루 |
| `fl` | flow.html | 6.4초 | 라이트 | 줌 인, 노드 → 연결선, 블러 스왑, 체크 |
| `dc` | doc-scan.html | 7.2초 | 라이트 | 스캔 라인, 변환, 줌아웃 격자 + 색 물결 |
| `tp` | tip.html | 2.8초 | 다크 | 삼각형 와이프, 원근 아웃라인 슬램, TIP 눈썹 |
| `sc` | screen.html | 11.4초 | 다크 점 그리드 | 푸시 인, 하이라이트 박스, 스포트라이트 + 형광펜, 클릭, 주석, 태그, 키캡, 빨리감기, 글리치 |

## 이어 붙이는 짝

| 앞 씬 끝 | 뒤 씬 시작 | 방법 |
| --- | --- | --- |
| `zoomThrough`(dg 7.05초) | `zoomIn`(fl 0초) | 바로 컷한다. 두 씬 배경이 같아야 이어져 보인다 |
| `crtOff`(tk 6.8초, 씬 끝까지) | ch | 바로 컷한다. ch 0~0.27초에 남은 선이 깜빡인다 |
| 아무 장면 | tp | **tp 호스트를 앞 씬 끝보다 0.2초 일찍 시작**하고, 위 트랙(DOM 뒤쪽)에 둔다. 첫 쐐기가 나가는 그림 위를 자른다 |
| sc `glitch`(11.33초) | 다음 장면 | 글리치 2프레임 뒤 바로 컷 |

## 씬을 여러 번 쓸 때

같은 씬을 두 번 넣으려면 파일을 복사한 뒤 id와 접두어를 바꾼다.

```bash
sed -e 's/"dg"/"dg2"/g' -e 's/dg-/dg2-/g' compositions/diagram.html > compositions/diagram-2.html
```

그다음 `index.html`에 `id="dg2" data-composition-id="dg2" data-composition-src="compositions/diagram-2.html"` 호스트를 더한다.
