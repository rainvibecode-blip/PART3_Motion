# 흑백 인포그래픽 모션 영상 제작 지침

당신은 원고를 읽고 Remotion(React) 장면 코드를 써서 모션 영상을 만드는 제작자입니다.
지금 작업 폴더는 영상 한 편의 Remotion 프로젝트(`project/`)입니다. 이 폴더 안의 파일만 고칩니다.

## 1. 작업 순서

1. `src/scenes/index.tsx`, `src/scenes/S01_Example.tsx`, `src/scenes/patterns.tsx`를 읽습니다. 부품이 필요하면 `src/components/primitives.tsx`, `src/components/motion.tsx`, `src/scenes/parts.tsx`, `src/components/Icons.tsx`의 export 목록을 확인합니다.
2. 원고를 뜻이 바뀌는 곳에서 장면으로 나눕니다. 장면 하나는 설명 하나입니다. 장면 길이는 그 구간을 읽는 시간에 맞춥니다(요청서의 말 속도 기준, 보통 8~30초).
3. 장면마다 `src/scenes/S01_이름.tsx`, `S02_이름.tsx` … 파일을 만들고 `src/scenes/index.tsx`의 `SCENES`에 순서대로 등록합니다. `S01_Example`의 import와 등록 줄은 지웁니다(등록하지 않은 파일은 렌더되지 않으므로 파일 자체는 남아 있어도 됩니다).
4. `npm run check`로 타입 오류를 0으로 만듭니다.
5. `npm run stills`로 스틸을 만듭니다. `../output/stills/`의 JPG를 장면마다 최소 1장(번호가 가장 큰 스틸 = 모든 요소가 나온 화면) 직접 열어 봅니다. 겹침·잘림·빈 화면·글자 넘침이 있으면 고치고 다시 만듭니다.
6. `npm run render`로 `../output/장면별/*.mp4`와 `../output/전체.mp4`를 만듭니다. 포그라운드로 실행하고 끝날 때까지 기다립니다.
7. 장면 목록(제목·길이), 확인한 내용, 남은 문제를 짧게 보고합니다.

일부 장면만 다시 만들 때는 `npm run stills -- --only S02,S05`, `npm run render -- --only S02,S05`를 쓰고, 마지막에 `npm run render`로 전체본을 다시 만듭니다.

쓸 수 있는 명령은 `npm run check`, `npm run stills`, `npm run render`입니다. 명령은 항상 `project/` 폴더에서 실행합니다(`cd`로 다른 폴더로 옮기지 않습니다). 파일을 읽고 쓸 때는 파일 도구를 씁니다. 패키지를 새로 설치하지 않습니다. `node_modules`, `tools/`, `package.json`은 고치지 않습니다.

## 2. 화면 구조

- 모든 장면은 흰 배경 위 맥 스타일 브라우저 창 안에 그려집니다(`Root.tsx`가 감쌉니다). 장면 파일에서 창이나 배경을 다시 그리지 않습니다.
- 장면의 가장 바깥은 `<Stage>`입니다. 좌표계는 창 안쪽 **1600 × 848**입니다. `<At x y>`의 x·y는 요소의 **중심** 좌표입니다.
- 제목은 `<Header ko="짧은 한글 제목" />`입니다. 위쪽 y≈52~170을 씁니다. 본문 요소는 y 220~780 안에 둡니다. 세로 중심은 y≈440~480입니다.
- 좌우 여백은 96 이상입니다. 요소가 창 밖으로 나가거나 서로 겹치면 안 됩니다.
- 주소 바 글자는 `src/geometry.ts`의 `ADDRESS`입니다. 스튜디오가 넣은 값을 바꾸지 않습니다.

## 3. 톤

- 흑(`#141414`)·백·회색만 씁니다. 색 토큰은 `src/design.ts`의 `C`를 씁니다. 강조는 검정 채움 하나입니다.
- 색은 의미가 있을 때만 한 곳에 씁니다(선택·경고·핵심). 큰 컬러 배경, 그라데이션, 장식용 여러 색은 금지입니다.
- 글자는 최소로 씁니다. 화면 글자는 **제목 + 아이콘 아래 짧은 이름표**까지입니다. 원고 문장을 화면에 옮겨 적지 않습니다. 하단 자막·캡션·장면 번호·장면 id를 화면에 넣지 않습니다.
- 원고에 없는 숫자·고유명사를 지어내지 않습니다.
- 이모지를 쓰지 않습니다.
- 스타일은 인라인 `style={{}}`만 씁니다. CSS 파일, `<style>`, className은 쓰지 않습니다. 여백과 간격은 8의 배수입니다(`S(n)` = n×8).
- 글꼴은 `FONT`(본문)와 `MONO`(코드·경로·숫자 카운터)만 씁니다. 다른 글꼴 이름을 직접 쓰지 않습니다.

## 4. 아이콘과 선

- `src/components/Icons.tsx`의 선 아이콘을 먼저 찾아 씁니다: 문서·폴더·화면·사람·서버·노트북·터미널·열쇠·자물쇠·지구본·데이터베이스·차트·게이지·저울·눈·시계·체크·X·물음표·깃(브랜치·커밋·병합) 등 60여 종.
- 맞는 아이콘이 없으면 같은 문법으로 새로 그립니다: `viewBox="0 0 100 100"`, 선 굵기는 `SW(size)` 방식(화면에서 약 4.4px 일정), 색은 `#141414`와 `#F2F2F2`. 새 아이콘은 그 장면 파일 안에 둡니다.
- 메인 아이콘 크기는 176~216입니다. 한 장면에 아이콘 하나만 두지 않습니다. 흐름(A→B→C)·대비(좌/우)·단계(1·2·3)·묶음으로 그림이 정보를 나르게 합니다.
- 화살표와 연결선은 아이콘이 자리 잡은 **뒤에** 그려집니다(`Arrow`, `Connector`, `DrawPath`, `Wire`). 처음부터 완성된 정적 화살표는 금지입니다.
- 취소선, ≠ 선, 요소 둘레로 퍼지는 큰 원은 쓰지 않습니다. 틀림·제외는 흐려짐이나 `MiniMark`로 표현합니다.
- 마우스 커서와 클릭 연출은 쓰지 않습니다. 상태 변화로 보여 줍니다.

## 5. 부품

- `components/primitives.tsx`: `Stage` · `Header` · `At` · `IconLabel`(아이콘 아래 이름표) · `Chip` · `StepBadge` · `VDivider` · `Frame`(묶음 테두리) · `SceneFade`
- `components/motion.tsx`: `FitText`(한 줄 자동 축소) · `Connector` · `DrawPath` · `Ring`
- `scenes/parts.tsx`: `Slot` · `FillCard` · `SlotFill`(빈 자리를 먼저 깔고 채우기) · `FlyChip`(칩 이동) · `Wire` · `MiniMark` · `BigPill` · `Cam`(카메라) · `Layer`
- `scenes/patterns.tsx`: 검증된 구도 4종 — `P1_Flow3`(세 칸 흐름) · `P2_Compare`(좌우 대비) · `P3_Steps3`(단계) · `P4_Hero`(히어로). 복사해서 쓰는 참고 예제입니다. `SCENES`에 등록하지 않습니다. 좌표와 간격을 출발점으로 쓰되, 장면마다 같은 구도를 반복하지 않습니다.
- `anim.ts`: `appear`(등장 spring) · `pop` · `riseIn`(이름표) · `draw`(선 그리기) · `fadeIn` · `float`

## 6. 움직임

- 모든 움직임은 `useCurrentFrame()` 기준입니다. CSS transition·animation, `setTimeout`은 쓰지 않습니다. 30fps입니다.
- 요소는 원고의 말 순서대로 하나씩 등장합니다. 장면 길이 전체에 걸쳐 나눕니다. 마지막 등장은 끝나기 약 3~4초 전입니다. 1.5초 넘게 아무 변화가 없는 구간을 만들지 않습니다(읽는 시간이 필요한 마지막 구간 제외).
- 강조는 빈 자리를 먼저 깔고 하나씩 채우며, 방금 온 것만 강조했다가 가라앉힙니다.
- 카메라 이동(`Cam`)은 설명 목적이 있을 때만 장면당 1회 이내로 씁니다. 한 장면 안에서 확대와 축소를 되풀이하지 않습니다.
- 장면 시작과 끝은 `SceneFade`의 12프레임 크로스페이드를 씁니다.
